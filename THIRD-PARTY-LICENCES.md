## The one that needed action

The SIL Open Font License requires the licence text to *accompany* the
fonts wherever they go. Flutter declares fonts under `fonts:` and does not
carry a text file next to them, so the six `.ttf` files shipped without
their licence — a violation that nothing would have reported, because the
app runs fine either way. The file is now listed under `assets:` and a test
in `test/platform_integration_test.dart` fails if it stops shipping.

The OFL also reserves the name: a *modified* IBM Plex may not be called
IBM Plex. AXIOM ships the fonts unmodified, so this does not apply — but it
would, if anyone ever adjusts a glyph.

## Nothing calls home

No component here opens an outbound connection at runtime. That is not a
side effect of the licences but a property the project tests for; see
[ADR-0005](docs/adr/ADR-0005-expertenmodus.md) and the checks in
`test/language_test.dart`.
