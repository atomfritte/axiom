# Capture

A few seconds pass between a thought arriving and a thought being written down. Whatever is not caught in that window is gone — which is why there is not one way in, but seven.

None of them is mandatory. The best one is the one you actually use.

## The ways in

| Way | When it carries |
|---|---|
| Persistent display | phone in hand, no unlocking — type straight into the notification |
| Button in the app | when AXIOM is open anyway |
| Quick setting | from inside any other app: swipe down, tap, write |
| Home screen widget | from the home screen; also shows the next action |
| Share | select text in another app and pick AXIOM |
| Long press on the app icon | capture, check-in and focus directly |
| Microphone in the input field | walking, driving, hands full |

The persistent display is the fastest the device allows: two seconds instead of ten. It lives under *System → Capture* and needs the notification permission — without it, it has nothing to appear in.

## What capture does not ask

No category, no project, no priority, no date. The field is active immediately, the keyboard is open, Enter saves. "Save & next" keeps the sheet open when several things arrive at once.

Dictated text is **appended, not replaced**: speak twice and you have two sentences; type first and you lose nothing.

## Sorting comes later

Everything captured lands in the inbox. Sorting happens deliberately, not on impulse — and there questions are allowed:

- **How hard is it to start?** Not how long it takes. Only the beginning.
- **What does it cost if it stays undone?** Consequences, not importance.
- **When does it start to hurt?** open, today, tomorrow, this week — or a date.
- **Does this only work in one place?** Only needed if the task cannot be done elsewhere.

Nothing asks for "priority". Why that axis leads astray is in [Tasks](kapitel:06).

A place here is only a name, not location access. A device routine can set it — "office Wi-Fi connected" is more accurate than any circle on a map, and costs no permission.
