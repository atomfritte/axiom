# One action

The main view shows exactly one thing — never a list to choose from. That is not a simplification, it is the core.

Choosing from a list is itself a decision, and decisions are the most expensive thing a screen can ask for when capacity is low. Fourteen open items cost energy before any of them has been started.

## What wins when several things apply

The order is fixed and can be read back:

1. **A rule that fired.** An appointment in ten minutes beats any depth you are currently in.
2. **A task already started.** As long as it runs, it is the output.
3. **The next startable task.** Highest rank from consequences, deadline and start energy.
4. **A split suggestion**, when nothing is within reach but something is waiting.
5. **The empty state.** No suggestion means: nothing is needed right now.

Whatever gets displaced does not disappear. A running task sits as a narrow strip above the card — visible, just not as the action.

## The rule number is tappable

Next to every output stands the rule that produced it. A tap opens the reasoning, the severity and the priority. A system you can recalculate is a system you do not have to believe.

## Three answers

- **Understood** — the rule counts as followed.
- **Later** — deferred, without comment.
- **Doesn't fit** — the rule speaks up less often.

"Doesn't fit" is not a failure; it is the feedback the weekly review later turns into retire suggestions. There is no fourth button that produces guilt, and no count of missed prompts.

## Where the list stays

The full stock is one tap away: the capacity line on the main view leads there, as does *System → Tasks*.

Knowing your stock is something other than deciding in the moment. Anyone who never sees what is on file keeps a second list in their head alongside — and then the system carries nothing. How the order comes about is in [Tasks](kapitel:06).
